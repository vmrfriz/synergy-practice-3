# Синергия: производственная практика

Кейс-задача №4

## Анализ выполненной задачи

1. Реализована базовая структура веб-приложения на Laravel.
2. Подготовлена архитектура для разделения пользовательского и административного интерфейсов.
3. Спроектирована работа с базой данных книг и их основными характеристиками.
4. Реализован каталог с возможностью просмотра доступных книг.
5. Добавлена логика сортировки/фильтрации книг по категории, автору и году.
6. Предусмотрена функциональность покупки и аренды книг на заданные сроки.
7. Для администратора предусмотрено управление каталогом, ценами, статусами и доступностью книг.
8. Учтён контроль сроков аренды и необходимость автоматических напоминаний пользователям.
9. Основная структура проекта разделена по стандартным компонентам Laravel, что упрощает дальнейшее сопровождение.
10. В ходе проверки выявлены отдельные места, требующие дополнительного тестирования и доработки перед окончательным завершением задачи.

## Рекомендации по устранению ошибок

- Добавить полноценные тесты для покупки, аренды и возврата книг.
- Проверить валидацию пользовательских данных и корректность обработки ошибок.
- Ограничить административные функции авторизацией и проверкой прав доступа.
- Исключить возможность аренды уже занятой или недоступной книги.
- Автоматизировать контроль окончания срока аренды через планировщик Laravel.
- Проверить корректность сортировки при пустых и некорректных параметрах.
- Добавить защиту от повторной покупки/аренды и дублирования операций.
- Улучшить обработку крайних случаев: удаление книги при активной аренде, изменение цены и отсутствие экземпляров.
- Дополнить README инструкцией по установке, настройке БД и запуску проекта.

- Создать 2 интерфейса: администратора и пользователя.
- Создать базу данных Ваших любимых книг.
